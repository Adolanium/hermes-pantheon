Install

Try it in a minute

You need Hermes Desktop 0.22.2 or later. You don't need a terminal. Tested on Windows 11, Linux and macOS.

  1. Install

    In Hermes Desktop, open Capabilities → Plugins and click Install from Git. Paste this address, click Review repository, then install.

    https://github.com/Adolanium/hermes-pantheon
    Prefer the terminal?
    hermes plugins install Adolanium/hermes-pantheon

    If it asks whether to enable the plugin, either answer works. That switch is for the agent side, and Pantheon has nothing there.

  2. Turn it on

    Pantheon now appears in Capabilities → Plugins. Flip its Desktop switch on.

    Pantheon

    Desktop plugins installed from a package start turned off, and this is the step people miss.

  3. Pick a god

    Type this in the message box and press Enter. The whole app changes on the spot, with no restart.

    /skin olympus

    Plain /skin steps through every theme you have.

Switch any time

Every Pantheon theme is a normal Hermes theme, so all the usual ways to switch work.

Message box
/skin selene opens a theme. /skin list shows them all, and /skin alone moves to the next.
Command palette
Ctrl K, or ⌘ K on macOS, then Change theme.
Settings
Settings → Appearance → Theme.

The names: . To go back to the stock look, type /skin nous. Ares answers to /skin mars, because Hermes keeps ares for its own Ember theme.

Small decisions, already made

  • One install, eighteen themes. All eighteen ship in a single plugin. Nothing to choose at install time, nothing extra to download later.
  • Nothing leaves your machine. The art and the fonts are packed into the plugin. Pantheon makes no network requests and works fully offline.
  • Your light or dark setting can't break the art. Each theme keeps its own palette in both modes. Five are light: Demeter, Apollo, Artemis, Hestia and Caduceus.
  • The chat stays readable. The art lives in the sidebar and the empty new-session screen. Once a conversation starts, it's text on a calm ground.
  • Honest about the edges. The decoration styles Hermes Desktop's own markup. If an update renames it, those touches fall back to the plain palette and nothing else breaks.
